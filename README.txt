Dice Dungeon RPG v0.6.2 — 装備システム版

追加
- 武器1枠 + 防具1枠の装備システム
- ホーム画面の装備欄から所持装備一覧へ移動
- 装備をタップすると即装備
- 武器ATK / 防具DEFをホームの総合ステータスへ反映
- 次回出撃時のHP / ATK / DEFにも装備補正を反映
- 装備状態をセーブ

現在のテスト所持装備
武器:
- 訓練用の剣 NORMAL ATK+0
- 鉄の剣 NORMAL ATK+3
- 狩人の刃 RARE ATK+6

防具:
- 旅人の服 NORMAL DEF+0
- 革の鎧 NORMAL DEF+2
- 守備隊の鎧 RARE DEF+4

この3種ずつは装備切替動作を確認するための初期所持。
次段階で装備ガチャと正式な30装備リストへ置き換える前提。
