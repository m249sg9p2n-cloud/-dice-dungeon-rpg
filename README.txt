DICE DUNGEON RPG v2.0.0 — ASCENSION UPDATE

今回の「神ゲー化」大型アップグレード

【ゲーム全体】
- ホームに冒険者RANK / POWER / COLLECTIONを追加
- クリア回数に応じて ROOKIE → HUNTER → SLAYER → CONQUEROR → LEGEND → MYTHIC
- 装備収集率を常時確認可能
- UIの押し心地・情報階層・レアリティ差を全面調整

【装備・やり込み】
- 同一装備3個で「+」 / 9個で「++」を正式実装
- + は装備ステータス1.5倍、++ は2.25倍
- 装備画面に所持数・強化段階を表示
- EPIC以上の武器スキルを実戦へ実装
  炎竜剣 / 三連星 / 逆境の魔剣 / 運命喰らい / 天命の大剣 / 神骰剣・天命
- EPIC以上の防具効果を実戦へ実装
  不屈 / 浄化 / LUCKY SIX / REBIRTH / AEGIS

【ガチャ】
- TOTAL PULLS表示
- EPIC+ 10回以内保証
- GOD 50回以内保証
- 天井まで残り回数を常時表示
- 既存のプチュン・全画面報酬・GOD演出を維持
- 重複が「ハズレ」ではなく装備強化につながる設計へ

【戦闘】
- MOMENTUMシステム追加
  READY → CHAIN → HOT → FEVER → OVERDRIVE
- 強い一撃を続けるほど演出上の熱量が上がる
- ACTIVE SKILLを戦闘画面に表示
- BOSS突入専用の全画面BOSS BATTLE演出
- 防具の致死回避・復活・次回③=6などを実装
- 最大ダメージ / 撃破数 / BOSS撃破数を内部記録

【ローグライク報酬】
- 毎戦3択を5候補からランダム抽選へ
- HP35%回復
- +80G
- ランATK +5
- ランDEF +3
- 最大HP +15 & HP15回復
- 毎回同じ3択だった状態を解消

【バランス思想】
- 高難度は維持
- ただし「死んでGOLD → 強化 → ガチャ → 重複強化 → 再挑戦」で
  明確に攻略できる成長曲線を強化
- GOD装備だけでなくEPIC/LEGENDARYにも実用的な価値を追加

【開発者モード】
- 既存の2秒長押し / 10タップ起動を維持
- +10,000 GOLD / 全ステージ解放 / 全装備 / GODガチャテストを維持
