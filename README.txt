Dice Dungeon RPG v0.7.6 — 強化UI修正 / ホーム演出強化

強化画面
- 強化ボタンが壊れて見えた原因はGOLD不足時の反応が分かりづらかったため。
- GOLD不足でもカードはタップ可能。
- タップすると「GOLD不足！ あと○○G必要」を画面上部に表示。
- 不足中は各カードに「あと○○G」を表示。
- 購入可能なら「強化できます」と緑表示。
- 購入成功時もレベルアップ通知を表示。

ホーム
- 情報配置はv0.7.5の分かりやすい構造を維持。
- DICE DUNGEONの小さなブランドヘッダー追加。
- 背景に控えめな魔法陣/光。
- 現在ミッションを金属・ゴールド調に強化。
- HP/ATK/DEFを色分け。
- 強化/装備/ガチャに左アクセント色と英字タグ。
- 選択中ダンジョンの見た目を強化。
- 出撃ボタンに軽い脈動発光。

狙い:
「分かりやすさ」は壊さず、RPGらしい豪華さだけ1段足す。
