Dice Dungeon RPG v0.7.3 — ワンボタン戦闘 / 全画面出目演出

変更点
- サイコロ本体のタップを廃止
- 画面下の同じボタンだけで操作
  1. 「サイコロを振る！」をタップ
  2. ①→②→溜め→③まで全自動
  3. 出目確定後、同じ場所が「攻撃する！」に自動切替
  4. 攻撃後はまた「サイコロを振る！」に戻る

- 各サイコロ確定ごとに全画面演出
  ①確定: 「3!」
  ②確定: 「3 ＋ 4!」
  ③確定: 「3 ＋ 4 × 5!」
- 出目1〜6ごとに色分け
- 数字は画面いっぱいに拡大、発光・衝撃・振動つき
- ③だけ従来より少し長めの溜め
- 最終倍率の「デン！」演出も継続

狙い:
親指をほぼ動かさず、1つのボタンだけで
ROLL → 結果を楽しむ → ATTACKまで完結させる。
