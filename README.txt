Dice Dungeon RPG v0.7.7 — COLOR UI

今回の変更
- 右上GOLDと🔊ボタンの重なりを修正。全画面の上部UIにサウンドボタン分の余白を確保。
- ホームの読みやすい構造は維持しつつ、セクションごとの色分けを強化。
- HP=青 / ATK=金 / DEF=緑。
- 強化=青 / 装備=金 / ガチャ=紫。
- ミッション、選択中ダンジョン、戦績カード、出撃ボタンの発色を強化。
- DICE DUNGEONのコンパクトなブランド帯を追加。
- 戦闘後3択報酬を完全にカラー分け。
  HP回復=緑
  GOLD=黄・金
  攻撃強化=赤・オレンジ
- 各報酬にアイコンボックスと英字タグを追加して一目で区別可能に。
- 強化画面もHP/ATK/DEFで色分け。

方針:
黒基調は残しながら、機能ごとに色を持たせて「暗いだけ」から脱却。
