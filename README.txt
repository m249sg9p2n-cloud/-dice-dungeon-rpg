Dice Dungeon RPG v0.7.2 — ワンタップ爽快ダイス版

変更点
- サイコロ操作を2タップ → 1タップへ変更
- 1タップで①②をロール
- ①②確定後に合計表示
- 約0.4秒の「倍率チャージ」を挟んで③が自動ロール
- ③停止時、出目1〜6ごとに専用カラーで巨大表示
  1=シルバー
  2=ブルー
  3=グリーン
  4=パープル
  5=オレンジ
  6=ゴールド
- ③停止時に「デン！」、拡散リング、画面反応、振動を追加
- 4以上で演出強化、5/6はさらに重い演出
- 6は専用の巨大ゴールドインパクト
- 666演出は従来演出に追加フラッシュ

狙い:
操作回数は最小限にしつつ、最後の倍率だけ「溜め → 自動停止 → デン！」で
結果を見る快感を強くする。
