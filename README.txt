Dice Dungeon RPG v0.6.1 — 永続強化実装版

追加
- ホーム画面にHP / ATK / DEFの永続強化を実装
- GOLDを消費してレベルアップ
- 強化値はセーブされ、次の出撃から反映

初期バランス
HP  : +5 / Lv、最大Lv20、初回100G、価格×1.35
ATK : +1 / Lv、最大Lv20、初回120G、価格×1.40
DEF : +1 / Lv、最大Lv15、初回150G、価格×1.45

最大時
HP 75 → 175
ATK 12 → 32
DEF 4 → 19

既存のv0.6.0セーブデータはそのまま引き継ぎます。
装備・ガチャは次段階。
