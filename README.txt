Dice Dungeon RPG v0.8.0 — MAX IMPACT
攻撃演出を「予兆 → 発射 → 加速 → 着弾 → ヒットストップ → 爆発 → 余韻」の一連演出へ再設計。

主な変更
- 全画面白フラッシュなし。眩しさではなく局所的な金/橙/赤の衝撃で派手さを出す。
- FINAL DAMAGEが一瞬チャージしてから弧を描いて加速。
- 着弾時はクロス斬撃、二重衝撃波、放射火花、巨大ダメージ数字。
- 54〜92msの短いヒットストップで「当たった瞬間」の重さを強化。
- 通常 / STRONG / CRITICAL / FINISHで演出量を段階化。
- 敵ノック、敵エリア振動、画面キックを再調整。
- KILL演出を金×赤のフィニッシュ仕様に強化。
- 攻撃音を一から再設計。チャージ音、低音DON、打撃クラック、金属トランジェント、
  強攻撃の報酬コード、CRITICALの上昇音、FINISH専用低音と決着音をレイヤー化。
- 音量をコンプレッサーでまとめ、単純な電子ビープ感を軽減。
- ミュート設定をFX側で統一。
- 敵名かぶり修正を継続。
